# brewhtml

Brew CSV/TSV html tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/brewhtml/

## Install / run

```bash
git clone https://github.com/theworker02/brewhtml.git
cd brewhtml
node src/cli.js
node --test
```
